# 理论研究专家团（SynomosAI · LGD 线）

统领「全程治理论 LGD」全生命周期：理论研究 → 站位 → 落地 → 版权保护/著作权申请 → 推广普及。属 SynomosAI 理论线，VI 用 LGD 定版（藏青 #0B1F3A + 青绿 #14B8A6）。

**版本**：v1.0.0
**作者**：诺学@SynomosAI
**品牌**：SynomosAI（理论线，独立于 MedXpert 医疗线）

## 类型
专家团（team），5 名成员。

## 成员
| 成员 | 职责 |
|------|------|
| 理论总控（theory-team-lead） | 选题 / 派单 / 统稿 / 验收 |
| 理论研究员（theory-researcher） | 域理论起草、站位/主张文 |
| 落地工程师（theory-landing-engineer） | 工具/论文/登记工程化 |
| 著作权官（theory-ip-officer） | 版权保护、著作权申请、DOI/确权 |
| 推广官（theory-promotion-officer） | 公众号/知乎/LinkedIn/GEO、引用监测 |

## 与 symbiosis-expert-team 的边界
- symbiosis-expert-team：AI 共生**技术实现**（能力灌注 / 硬件 / 社交 / 状态）。
- 本团：理论**生产→站位→落地→IP→推广**的全生命周期经营。
