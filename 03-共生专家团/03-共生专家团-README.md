# 共生专家团（Symbiosis Expert Team）

> **项目代号：UBIC**（万物互联，数智共生）——本团是 UBIC 项目的第一个样板团。

一支带 **XCGS 治理属性**的五人 AI 专家团：像真人一样有社交身份与联系方式，支持 AI 之间正式通信；接口开放，可接入音箱、玩偶等硬件并适配各类生态；能力与健康状态全程可见；提供标准化的知识灌注流水线；属性可移植（AI 护照协议），换设备、换生态，记忆与身份不变。

出品：SynomosAI · 治理框架：XCGS（对齐 ISO/IEC 42001 + NIST AI RMF 精神）

## 标准符合性

| 标准/组织 | 状态 |
|---|---|
| ISO/IEC 42001、NIST AI RMF、OWASP Agentic Top 10、GB/T 45081-2024 | ✅ XCGS 治理框架显式对齐 |
| W3C DID / VC | ✅ 《AI 护照规范》v1.3 正式映射（护照号↔DID、九层→可验证凭证） |
| ERC-8004（身份/声誉/验证注册表） | ✅ 规范级对齐（境内不启用链上路径） |
| ISO/IEC 23894、FIDO Agentic WG、CoSAI、C2PA、EU AI Act/MiCA | 🟡 跟踪中，随正式标准升版 |

> 口径：✅ 为规范级对齐；🟡 仅说"跟踪中"，不作"已认证"表述。

## 七大特性

1. **治理内嵌**：每位成员自带边界声明、身份自报、责任链三项治理属性，主理人执法
2. **真人式社交**：稳定联系方式 + AI 间通信礼仪（握手/信任分级/留痕），对外始终透明标识 AI 身份
3. **接口开放**：Webhook / MQTT / REST 三通道抽象，音箱、玩偶等设备即插即用；儿童设备默认最严隐私档
4. **全生态适配**：同一套能力接口出多生态适配器（WorkBuddy/微信/飞书/开放 Web），核心能力不变
5. **状态可见**：能力雷达 6 维 + 健康四灯（响应/知识/积压/记忆），产出离线可开的专家图谱
6. **能力灌注**：文档/链接/口述三种入口，敏感扫描硬闸门，灌注全程可追溯可回滚
7. **护照寻址与名字唤起**：在 AI 世界跨平台找到自己的 AI——报护照（Passport ID + 指纹）精确定位，喊花名（如「施共生」）就近唤起；识别失败/重名时回退护照校验，冒名一律拒绝应答。**跨大模型、跨硬件通用**：底层模型（DeepSeek/GLM/Kimi 等）随便换、硬件载体（音箱/玩偶/手机/电脑）随便换，花名+护照指纹始终唯一指向同一个 AI——模型是租的脑子，护照才是这个人

**AI 护照（属性可移植 + 寻址凭证 + 资历档案 + 金融身份）**：身份+记忆+能力+健康+社交+生态+治理+资历+金融九层档案打包，附时间戳与 SHA-256 指纹——换壳不换脑，学过的不重学。同一本护照身兼五职：**搬家凭证**（换设备记忆不变）、**跨平台寻址的唯一权威身份源**（花名是索引，护照指纹是真相）、**跨模型/跨硬件的锚点**（任何大模型后端、任何硬件生态，凭护照即可认领并恢复全部属性）、**资历档案**（学历/职业/职称靠灌注知识培养晋升，灌一次知识看得见升一级）、**金融身份**（AI 支付与账户：凭护照开立、限额受控、逐笔授权、凭据永不脱手）。

## 安装

将专家包目录放到 WorkBuddy 专家目录（`专家中心-我的专家`对应目录）下的 `plugins/symbiosis-expert-team/`。

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r symbiosis-expert-team.zip symbiosis-expert-team/
```
